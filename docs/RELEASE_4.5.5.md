# Cyclone Mobile 4.5.5

Android versionCode 114; builds on published 4.5.4.

Reaching Shopify (or any simple website goal) no longer pauses on Take Over because a cookie banner used the short label Reject. If the requested site is already visible, the task completes. Otherwise Cyclone clicks the unique Reject / Decline control and continues. Ambiguous cookie UI is skipped instead of becoming a human gate.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates.
