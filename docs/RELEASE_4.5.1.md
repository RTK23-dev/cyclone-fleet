# Cyclone Mobile 4.5.1

Android versionCode 110; builds on published 4.5.0.

Liquid glass was too clear: launcher icons showed through the Model / Intelligence / Autonomy sheet, and Brain's Skills / Apps / Outcomes track disappeared so selected pills floated over the page. Surfaces now use Apple Regular fill — milky white in light mode, dense charcoal in dark mode — with stronger Kyant blur. Overlay chrome always uses white type on dark glass, matching the Ask Cyclone bar. Brain metrics sit in one tray; the segmented control is a single clipped bar.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates. Physical-device glass contrast remains UNVERIFIED.
