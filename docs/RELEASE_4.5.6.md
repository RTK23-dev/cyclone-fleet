# Cyclone Mobile 4.5.6

Android versionCode 115; builds on published 4.5.5.

Cookie banners follow Google ARTEMIS transient-overlay handling: local action burst, never Take Over. Shopify's Accept all / Reject bar is clicked as Reject. Competing labels prefer Reject all. If only Cookie settings is visible, Cyclone opens settings then rejects on the next observe. Simple website landings still complete when the host is already on screen.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates.
