# Cyclone Mobile 4.5.0

Android versionCode 109; builds on published 4.4.8 with one liquid-glass generation.

Ask Cyclone, overlay, and Settings no longer stack a second darkened box inside the Apple glass selector. The 3-option intelligence and autonomy bars inherit the parent glass and only move a light chromatic lens on a spring. Overlay glass is translucent enough for refraction, with chromatic aberration enabled and the extra rim removed. Nested leftover shells (alpine weather photos, dead V32 AI/Brain/Settings, v31 cards, modules screen) stay deleted.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates. Physical-device liquid-glass validation remains UNVERIFIED.
