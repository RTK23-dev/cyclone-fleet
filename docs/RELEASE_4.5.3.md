# Cyclone Mobile 4.5.3

Android versionCode 112; builds on published 4.5.2.

Starting a task no longer collapses Ask Cyclone into a full-screen white wash. The composer stays at the bottom; the live task sits above it. A second request queues and starts automatically when the first finishes or fails — Steer is optional, not a launch gate. Compact glass no longer paints a fillMaxSize theme backdrop over the host app.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates.
