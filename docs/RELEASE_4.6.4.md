# Cyclone Mobile 4.6.4

Android versionCode 124; builds on published 4.6.3.

The Ask Cyclone plus sheet was still a dumping ground. 4.6.4 keeps only the actions people use, and moves phone autonomy out of the live canvas.

## Ask Cyclone

- **+** is Camera, Photos, Files, Create a routine, Share screen, and the model's own intelligence chips.
- Screenshot / open app / write text / deep research / explain this screen are gone from the sheet.
- Intelligence is just Max / High / Low (or whatever the selected OpenRouter model actually exposes). No helper copy, no Default glass button.
- Phone autonomy is no longer on this page. It stays a Settings row.

Gradient canvas, overlay model picker, and Easy named-app opens are unchanged.

Release requires Mobile CI tests, lint, assembly and existing signing/update-continuity gates. Physical Pixel 8 remains UNVERIFIED.
